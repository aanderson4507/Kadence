# Kadence

Kadence is a goals and productivity dashboard built with React, TypeScript, and Vite.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The initial dashboard screen is in `src/App.tsx`, with its styles in `src/App.css`
and shared design tokens in `src/index.css`. Figma-exported SVGs are stored in
`public/assets`.
